# PixShift 产品需求文档

## 1. 文档状态

- 阶段：MVP 需求已确认
- 目标平台：macOS
- 目标用户：个人用户、企业批处理用户
- 发布策略：先自用验证，后续提交 Mac App Store
- 最低系统：macOS 15

选择 macOS 15 是为了使用现代 SwiftUI、Swift Concurrency 和 Observation 编写单一路径实现，同时仍保留合理的设备覆盖。当前开发环境为 macOS 26.6 / Xcode 26.6 / Swift 6.3；首版不为 macOS 14 及以下编写兼容分支。

## 2. 产品目标

用户可以在一个原生 macOS 工具中批量导入图片，统一设置尺寸、裁剪和输出规则，安全地导出新文件，并清楚看到处理进度与失败原因。

### 成功标准

- 常见批处理可以在一个窗口内完成，不要求逐张配置。
- 原文件永不覆盖、永不修改。
- 同一批图片严格应用同一组处理参数。
- 取消任务后，本次任务已生成的文件会被清理。
- 无法处理的单张图片不会中断其余队列。

## 3. 核心用户流程

1. 用户通过拖放、文件选择器或文件夹选择器导入图片。
2. 应用校验格式并展示待处理列表。
3. 用户选择尺寸模式并填写参数。
4. 如启用裁剪，用户设置比例与统一裁剪区域。
5. 用户选择输出格式、品质、目录和命名规则。
6. 应用预检输出权限、参数和潜在文件名冲突。
7. 用户开始批处理，查看进度，必要时取消。
8. 完成后查看成功数量与失败清单，并可在 Finder 中显示输出位置。

## 4. 功能需求

### 4.1 导入

支持：

- 选择一个或多个图片文件。
- 选择一个或多个文件夹。
- 将文件或文件夹拖放到主窗口。
- JPEG、PNG、WebP、HEIC、TIFF。
- 按导入顺序形成稳定队列，允许移除单项和清空列表。

文件夹扫描规则：

- 只读取文件夹当前层级。
- 不递归进入子文件夹。
- 忽略隐藏文件和隐藏目录。
- 不支持 RAW 和 GIF；遇到时标记为不支持，不加入处理队列。
- 对重复 URL 去重，同一文件只出现一次。

### 4.2 尺寸处理

尺寸模式互斥，首版包含：

1. 指定宽度和高度（像素）。
2. 按百分比缩放。
3. 固定宽度、按原比例计算高度。
4. 固定高度、按原比例计算宽度。
5. 限制最长边。
6. 限制最短边。

通用规则：

- 输入必须为正整数；百分比必须大于 0。
- 允许放大，但“允许放大”默认关闭。
- 关闭“允许放大”时，任何模式都不会让输出尺寸超过原图。
- 开启时允许因插值产生画质降低，界面给出非阻塞提示。
- 指定宽高与原比例不一致时，先按目标比例居中裁剪，再缩放到精确尺寸，不拉伸图像。
- 计算结果至少为 1 × 1 像素。

### 4.3 裁剪

支持默认居中裁剪和 Photoshop 风格的自定义裁剪：

- 预设比例：原始比例、自由、1:1、4:3、3:2、16:9。
- 允许输入自定义宽高比。
- 裁剪框显示四边与四角控制柄；拖动控制柄调整范围，拖动框内区域改变位置。
- 用户选择一张代表图片作为裁剪定位画布；默认使用队列第一张。
- 裁剪结果以归一化坐标保存，并应用到批次内所有图片。
- 不提供逐张裁剪或逐张微调。
- 混合横竖图时保持同一裁剪比例和归一化位置；超出某张图片有效范围时，将裁剪框平移到最近的有效范围，不改变比例。

这里的画布只用于定义裁剪区域，不是最终压缩质量、文件大小或处理效果的实时预览。

### 4.4 输出格式与品质

- 默认“保持原格式”。
- 可统一转换为 JPEG、PNG、WebP、HEIC 或 TIFF。
- JPEG 与 WebP 显示品质设置，范围 1–100，默认 85。
- HEIC 首版也提供品质设置，默认 85。
- PNG 与 TIFF 使用无损输出，不展示有损品质控件。
- 含透明通道的图片转换为 JPEG 时，默认以白色填充透明区域，并允许自定义背景色。

### 4.5 元数据

默认策略：

- 保留 EXIF 中的拍摄时间、相机信息等兼容字段。
- 保留 ICC 色彩配置，避免明显色差。
- 移除 EXIF 与 XMP 中的 GPS 位置信息。
- 不承诺跨格式保留格式专属或厂商私有字段；无法映射的字段安全丢弃。
- 输出像素已按方向校正，输出方向写为标准方向，避免重复旋转。

首版不提供元数据策略开关。

### 4.6 输出目录

- 默认将每张图片导出到其原文件所在目录。
- 用户可选择一个统一输出目录。
- 设置中可持久保存统一输出目录。
- 当沙盒没有原目录写权限时，开始任务前请求用户授权对应目录；拒绝后不启动任务。
- 原文件始终只读，不支持覆盖导出。

### 4.7 文件命名

默认规则：

```text
{name}_{width}x{height}_{index}.{ext}
```

变量定义：

- `{name}`：不含扩展名的原文件名。
- `{width}` / `{height}`：实际输出像素。
- `{index}`：当前批次序号，从 1 开始，按总数补零，例如 001。
- `{ext}`：实际输出格式的推荐扩展名。

用户可在设置中编辑命名模板。首版支持变量 `{name}`、`{width}`、`{height}`、`{index}`、`{ext}`。模板必须至少产生一个非空文件名；非法文件名字符替换为 `_`。

同名处理：

- 永不覆盖已有文件。
- 若目标名称存在，在文件名末尾追加 `-2`、`-3` 等，直到获得可用名称。
- 自动改名发生在任务预检阶段，任务执行期间保持稳定。

### 4.8 进度、失败与取消

处理中展示：

- 已完成数量 / 总数量。
- 当前总体进度条。
- 成功和失败数量。
- 取消按钮。

错误策略：

- 单张图片损坏、无权限、编码失败或磁盘空间不足时，记录失败并继续其余任务。
- 结束页列出失败文件和可理解的失败原因。
- 不显示预计输出文件大小。

取消策略：

- 取消后停止调度新任务，并尽快终止尚未提交的编码工作。
- 删除本轮已经成功生成的全部输出和临时文件。
- 只删除任务台账中明确记录为“由本轮新建”的文件。
- 如个别文件清理失败，结果页必须列出路径和原因，不宣称已完全取消。

### 4.9 设置与状态保存

保存：

- 上一次处理参数。
- 用户选择的统一输出目录及其安全作用域书签。
- 自定义命名规则。
- JPEG、WebP、HEIC 品质。
- 本机累计成功处理图片数量。

不保存：

- 导入队列。
- 历史任务。
- 撤销栈。
- 每张图片的处理记录。

### 4.10 多语言

- 首版支持简体中文和英文。
- 默认跟随系统语言。
- 所有用户可见字符串进入 String Catalog，不在代码中硬编码。

### 4.11 本地统计

- 仅累计“成功产生输出文件的图片数量”。
- 取消任务并成功删除输出后，该任务不计入成功累计数；统计提交发生在任务最终确认完成之后。
- 计数仅保存在本机，不上传、不联网、不记录文件名、路径、尺寸或图片内容。
- 该本地计数没有关闭开关，可在设置页查看。

## 5. 非功能需求

- 原图安全：任何处理均写入新文件。
- 大批量稳定性：采用有界并发，避免一次解码全部原图。
- UI 响应：扫描、解码、处理和写盘均不得阻塞主线程。
- 一致性：同一输入和同一设置应产生相同尺寸、裁剪范围和命名结果。
- 可访问性：控件具备 VoiceOver 标签、键盘焦点与足够对比度。
- 隐私：图片全程本地处理，不请求网络权限。

## 6. 首版不包含

- RAW、GIF 或动图处理。
- 逐张独立处理参数。
- 智能主体、人脸或内容感知裁剪。
- 处理前后对比、压缩效果实时预览、预计文件大小。
- 历史记录、撤销、预设管理。
- 命令行、Automator、快捷指令集成。
- 付费、试用、自动更新或远程分析。
- 递归目录扫描与输出目录层级复刻。
