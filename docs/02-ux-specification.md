# PixShift 交互与界面规格

## 1. 设计原则

- 遵循原生 macOS 工具风格，优先使用系统控件、菜单、表格、检查器和标准快捷键。
- 主流程保持在一个窗口中，设置使用独立 Settings 场景。
- 批处理参数对整个队列生效，避免给用户造成可逐张配置的误解。
- 高风险动作必须明确：开始前预检，取消时说明会删除本轮输出。

## 2. 主窗口结构

窗口建议最小尺寸 900 × 600。

```text
┌──────────────────────────────────────────────────────────────┐
│ 工具栏：添加文件｜添加文件夹｜移除｜清空          开始处理 │
├───────────────────────────────┬──────────────────────────────┤
│ 图片队列                      │ 批处理设置                    │
│ 缩略图 / 名称 / 尺寸 / 格式   │ 1. 尺寸                       │
│                               │ 2. 裁剪                       │
│ 空状态兼作拖放区域             │ 3. 格式与品质                 │
│                               │ 4. 目录与命名                 │
├───────────────────────────────┴──────────────────────────────┤
│ 状态栏：有效 120｜忽略 3｜错误 0                             │
└──────────────────────────────────────────────────────────────┘
```

窄窗口下右侧设置区保持最小宽度，图片队列优先收缩；不设计 iPhone 式单列导航。

## 3. 导入交互

### 空状态

- 主文案：“拖放图片或文件夹到这里”。
- 次级按钮：“选择图片”“选择文件夹”。
- 标注支持格式：“JPEG、PNG、WebP、HEIC、TIFF”。

### 导入结果

- 表格行显示缩略图、文件名、原尺寸、格式和状态。
- 非支持格式、隐藏项与子目录不加入队列。
- 一次导入包含被忽略项目时，用非阻塞摘要说明数量和原因。
- 导入后自动选中第一项，但所有设置仍作用于整个队列。

### 菜单与快捷键

- `⌘O`：选择图片。
- `⌘⇧O`：选择文件夹。
- `Delete`：移除选中项。
- `⌘A`：选择全部队列项。
- `⌘,`：打开设置。
- `⌘Return`：开始处理（仅参数有效时）。

## 4. 尺寸设置

使用分段选择器或弹出菜单选择模式：指定宽高、百分比、固定宽度、固定高度、最长边、最短边。

- 数值字段根据模式动态显示，单位固定为 `px` 或 `%`。
- “允许放大”开关默认关闭。
- 指定宽高模式旁显示说明：“比例不同时将居中裁剪，不会拉伸”。
- 参数无效时就地显示错误，并禁用“开始处理”。
- 在设置区显示只读结果摘要，例如“输出最长边不超过 2048 px”。

## 5. 裁剪交互

### 入口

- 裁剪开关关闭时，不额外裁剪；指定宽高为满足精确尺寸仍会执行隐式居中裁剪。
- 打开裁剪后显示比例选择器与“调整裁剪区域”按钮。

### 裁剪面板

使用独立 sheet：

- 左侧/主体为代表图片画布。
- 裁剪框之外显示半透明遮罩。
- 四边和四角均有可拖动控制柄；鼠标悬停时使用对应的调整光标。
- 拖动框内可移动区域，按比例模式约束裁剪框。
- 比例菜单包含原始、自由、1:1、4:3、3:2、16:9、自定义。
- 可从队列中切换代表图片，仅用于帮助确定统一的归一化裁剪位置。
- “重置为居中”恢复最大可用居中裁剪框。
- “应用到全部”保存归一化裁剪区域并关闭 sheet。

面板明确提示：“同一比例和相对位置将应用到所有图片；不支持逐张调整。”

键盘可访问性：方向键移动 1 px，`Shift` + 方向键移动 10 px，`Escape` 取消，`Return` 应用。

## 6. 输出设置

- 格式默认“保持原格式”，其余为 JPEG、PNG、WebP、HEIC、TIFF。
- JPEG、WebP、HEIC 显示品质滑块和数字字段。
- 目标为 JPEG 且队列包含透明图时，显示背景色控件，默认白色。
- 目录默认“原图片所在目录”；可切换“统一目录”并选择文件夹。
- 命名规则显示模板输入框和即时的文件名示例。这里只计算名称，不渲染图片。
- 模板错误、目录权限不足或目标格式不支持时就地提示。

## 7. 开始前预检

点击“开始处理”后，先执行快速预检：

- 队列非空。
- 所有参数有效。
- 输出尺寸和格式可编码。
- 命名结果有效且已经完成冲突避让。
- 目标目录可写。
- 可用磁盘空间能够支撑临时写入；无法可靠估算时仅检查系统报告的可用容量，不显示文件大小预测。

如需补充目录权限，弹出系统文件夹授权面板。只有全部必需授权完成后才创建任务。

## 8. 处理进度

处理时设置区切换为进度视图：

- 总体进度条与“37 / 120”。
- 成功、失败数量。
- 当前阶段：准备、处理中、正在清理或完成。
- “取消处理”按钮。

取消确认文案：“取消后将停止处理，并删除本次已经生成的文件。原图片不会受到影响。”

确认后按钮禁用，状态变为“正在取消并清理…”。清理完成前不得关闭窗口而不提示。

## 9. 完成与失败

成功页显示处理成功数量和“在 Finder 中显示”按钮。存在失败时使用可展开列表，包含：

- 原文件名。
- 简明原因。
- “在 Finder 中显示原文件”。

取消结果需区分：

- 已取消，所有本轮输出已清理。
- 已取消，但有若干文件无法清理；列出遗留文件。

## 10. 设置窗口

首版设置项：

- 默认输出方式：原目录 / 统一目录。
- 已保存的统一输出目录。
- 默认命名模板。
- 默认 JPEG、WebP、HEIC 品质。
- 恢复默认设置。
- 本机累计成功处理图片数量（只读）。

系统语言决定应用语言，不增加应用内语言切换控件。

## 11. 本地化与可访问性

- 简体中文为产品设计基准，英文文本不得依靠固定宽度。
- 数字、复数和计数使用 String Catalog 的本地化能力。
- 不以颜色作为唯一状态信号；错误同时提供图标和文字。
- 所有图标按钮提供可见 tooltip 与 VoiceOver label。
- 裁剪控制柄提供足够的可点击区域，视觉尺寸可小于命中区域。
