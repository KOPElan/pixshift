## 2026-08-31：布局修正与异常退出恢复

### 已完成

- 修正主窗口初始状态的纵向布局：左右面板均占满窗口可用高度并从顶部布局。
- 左侧队列底部操作栏固定在面板底部，不再因空状态居中而移动到窗口中部。
- 右侧设置表单占满面板高度并使用全高度滚动区域，窗口较小时可以完整滚动所有设置。
- 新增持久化 `RunLedger`，逐项记录本轮临时文件和已提交输出。
- 应用启动时检测未完成批次，并允许用户选择清理本轮生成文件或保留文件。
- 取消与异常退出恢复共用台账清理路径；仅删除台账明确记录的文件。
- 最终输出记录设备号与 inode；若同一路径的文件已被外部替换，恢复流程拒绝删除并保留台账以供处理。
- 批处理由串行调度升级为 2–4 路有界并发，并发度根据活动 CPU 和物理内存自动分档。
- 调度器只维持固定数量的活动任务；任务完成后才补充下一项，取消后不再启动尚未调度的图片。
- 每个固定工作槽复用独立图片处理器，输出命名分配和运行台账继续由 actor 隔离，保持无覆盖和恢复安全。

### 自动化验证

41 个单元/集成测试全部通过，其中新增 5 个运行台账与处理流水线集成测试，以及 5 个并发与取消测试：

- 台账持久化临时文件与已提交输出。
- 清理只移除台账记录的文件并保留无关文件。
- 已不存在的记录按成功清理处理。
- 文件身份变化时拒绝删除并保留恢复台账。
- 图片成功提交后台账只保留最终输出，不残留临时文件记录。
- 并发策略在不同 CPU/内存配置下始终返回 2–4 个工作任务。
- 有界任务组不会超过配置的并发上限。
- 取消后不再调度队列中尚未开始的任务。
- 多图片并发提交不会丢失或破坏台账记录。
- 处理开始前已经取消的任务不会创建输出文件。

## 2026-08-30：首个端到端批处理版本

### 已完成

- 创建 `PicTool.xcodeproj`、macOS App target 和 XCTest target。
- 配置 macOS 15、Swift 6、严格并发、App Sandbox 和用户选择文件读写权限。
- 建立原生 SwiftUI 主窗口、图片队列、批处理设置、进度状态和 Settings scene。
- 支持文件选择、文件夹选择和 Finder URL 拖放；文件夹扫描不递归、不读取隐藏文件。
- 支持 JPEG、PNG、WebP、HEIC、TIFF 的读取与导出，默认保持原格式，也可批量转换格式。
- 完成六种尺寸模式、禁止/允许放大、exact 模式居中裁剪和 alpha 到 JPEG 白底合成。
- 输出时归一化 EXIF 方向、移除 GPS，并为 Image I/O 格式保留兼容元数据与色彩空间。
- 接入官方 libwebp v1.6.0 的 arm64/x86_64 静态 XCFramework，并实现 Swift WebP RGBA 编码封装。
- 支持品质设置、原图各自目录或统一目录、自定义命名模板和批次内/磁盘同名自动避让。
- 每个文件使用同目录临时文件后提交，已有文件绝不覆盖。
- 批次失败不会中断后续图片；显示进度、成功数和失败数。
- 支持取消；取消后清理本轮已经生成的文件，清理失败会明确显示残留数量。
- 仅在整批正常完成时累计本机成功处理图片数量。
- 保存上一次尺寸、格式、品质、命名和目录模式；统一输出目录通过 security-scoped bookmark 保存。
- 完成统一裁剪编辑器：代表图片切换、原始/自由/预设/自定义比例、遮罩与九宫格、框内移动、四边和四角控制柄、键盘微调及居中重置。
- 裁剪区域以归一化坐标保存，并按相同比例与相对中心安全映射到混合横竖图批次。
- 裁剪面板按需加载最高 1600 px 的临时预览，不在队列中常驻大图像素。
- 导入扫描与批处理期间显式维持用户选择文件/文件夹的 security-scoped access 生命周期。
- 开始处理前使用唯一隐藏临时文件验证全部目标目录可创建并删除文件，探测完成后不留残余。
- 权限不足时通过系统文件夹面板一次性补充授权；取消或授权仍不完整时整批不启动并明确显示不可写目录数量。
- 本机签名 Debug 构建通过严格签名验证，确认包含 App Sandbox 与用户选择文件读写 entitlement。
- 完成简体中文与英文 String Catalog。
- arm64 Debug 测试与 x86_64 Release 编译通过。
